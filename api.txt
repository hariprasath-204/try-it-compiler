Compiler API Fallback System Documentation
=========================================
Our online compiler architecture implements a highly scalable, robust 10-Tier Fallback mechanism specifically designed to handle extreme concurrent load (e.g., 200+ students simultaneously executing code) without suffering from IP rate-limit bans.

The execution logic runs entirely on the **Client-Side (Frontend)** in `client/src/services/execution.js`. This guarantees that all API requests are distributed across the individual IP addresses of the 200 students' computers, effectively avoiding strict per-IP rate limits that would normally crash a single centralized backend server.

Below are the detailed limits and specifications for all 10 remote compiler APIs mapped in this system. 

IMPORTANT NOTE: Because of severe cryptomining abuse over the last few years, almost all fully free, unauthenticated public execution APIs have shut down. The first 3 APIs are the only remaining stable free public APIs. APIs 4-10 require purchasing commercial API keys and registering an account to unlock them.

----------------------------------------------------
1. Judge0 CE Public API (Primary Free Provider)
----------------------------------------------------
- Endpoint: https://ce.judge0.com/submissions
- Role: Primary compiler. Extremely fast, secure, and reliable.
- Rate Limits (Per IP): Max 50 requests per day, 1 request per second.
- Requirements: Free, no key required.

----------------------------------------------------
2. Paiza.io API (Secondary Free Fallback)
----------------------------------------------------
- Endpoint: https://api.paiza.io/runners/create
- Role: First fallback.
- Rate Limits (Per IP): Undisclosed, but heavily rate-limits rapid automated requests.
- Requirements: Free guest access (`api_key=guest`).

----------------------------------------------------
3. Wandbox API (Tertiary Free Fallback)
----------------------------------------------------
- Endpoint: https://wandbox.org/api/compile.json
- Role: Final free failsafe.
- Rate Limits (Per IP): Generous open-source limits. Subject to OCI runtime errors under massive global load.
- Requirements: Free, no key required.

----------------------------------------------------
4. JDoodle API (Commercial)
----------------------------------------------------
- Endpoint: https://api.jdoodle.com/v1/execute
- Rate Limits: 200 free executions per day total. Paid plans available for up to 100,000/day.
- Requirements: Requires `clientId` and `clientSecret`.

----------------------------------------------------
5. Sphere Engine API (Commercial)
----------------------------------------------------
- Endpoint: https://[ID].compilers.sphere-engine.com/api/v4/submissions
- Rate Limits: Based on enterprise SLA plan.
- Requirements: Requires `access_token`.

----------------------------------------------------
6. HackerEarth API v4 (Commercial)
----------------------------------------------------
- Endpoint: https://api.hackerearth.com/v4/partner/code-evaluation/submissions/
- Rate Limits: Based on partner agreement.
- Requirements: Requires Partner `client_secret`.

----------------------------------------------------
7. Judge0 Premium (Commercial via RapidAPI)
----------------------------------------------------
- Endpoint: https://judge0-extra.p.rapidapi.com/submissions
- Rate Limits: Defined by RapidAPI subscription tier (Basic, Pro, Ultra, Mega).
- Requirements: Requires `X-RapidAPI-Key`.

----------------------------------------------------
8. Glot.io API (Commercial / Self-Hosted)
----------------------------------------------------
- Endpoint: https://run.glot.io/languages/
- Rate Limits: Free tier discontinued due to abuse. Requires Patreon subscription or local self-hosting.
- Requirements: Requires `Authorization: Token`.

----------------------------------------------------
9. CodeX API (Open Source Wrapper)
----------------------------------------------------
- Endpoint: https://api.codex.jaagrav.in
- Rate Limits: Extremely unstable; frequently returns "No healthy upstream" 102508 errors.
- Requirements: Free, but currently non-functional for production.

----------------------------------------------------
10. OneCompiler API (Commercial)
----------------------------------------------------
- Endpoint: https://onecompiler.com/api/code/exec
- Rate Limits: Based on RapidAPI or direct enterprise plans.
- Requirements: Requires complex CSRF token auth or enterprise keys.
